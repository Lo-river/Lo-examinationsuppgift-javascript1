# Space Quiz – JavaScript 1 Exam Project

Welcome to **Space Quiz** — an interactive quiz about space.  
A task from my JavaScript 1 course. This project contains a set of exercises and small apps in vanilla JavaScript, HTML and CSS.  
I built this project as part of my studies at Nackademin (YH – Stockholm).

**Live Demo:** https://lo-river.github.io/Lo-examinationsuppgift-javascript1/  
**GitHub Repo:** https://github.com/Lo-river/Lo-examinationsuppgift-javascript1  

---

## Features

- Start and navigate through quiz questions  
- Different question types:
  - True / False  
  - Multiple choice  
  - Checkbox (select multiple answers)  
  - Radio buttons (single choice)  
- Result summary with feedback in colors (green / orange / red)  
- Dark / light mode toggle  
- Visual theme with stars animation and planetary design  
- Responsive layout for desktop and tablet  
- No backend — everything runs in browser  

---

## Technologies & Tools

- **HTML5** — structure  
- **CSS3** — styling, transitions, media queries  
- **Vanilla JavaScript** — quiz logic and interactivity  
- **Responsive design** — adapts to screen size  
- **Dark / Light mode switch**
